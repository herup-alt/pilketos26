Panduan Implementasi Server Resmi (Production)

Aplikasi ini saat ini berjalan dalam versi Simulasi Lokal (LocalStorage) yang ideal untuk demonstrasi, uji coba panitia, atau ujian lokal pada satu perangkat.

  • Untuk Pemilihan Resmi Multi-Perangkat: Hubungkan frontend ini dengan backend API (Node.js/PHP/Python) dan Database Server (MySQL/PostgreSQL).
  • Integritas Token: Validasi token harus dilakukan di sisi server untuk mencegah manipulasi browser client.
  • Kerahasiaan Suara: Simpan tabel suara (`votes`) tanpa foreign key yang merujuk pada identitas pemilih (`voters`).
